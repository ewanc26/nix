# Hosts

This directory contains host-specific configurations for different machines.

## Structure

Each host has its own subdirectory:

- `default.nix` — Main configuration for the host
- `hardware-configuration.nix` — Hardware-specific config (generated by `nixos-generate-config`)

## Current Hosts

### Server

## Adding a New Host

1. Create `hosts/YOUR-HOSTNAME/`
2. Generate hardware config:
   ```bash
   sudo nixos-generate-config --show-hardware-config > hosts/YOUR-HOSTNAME/hardware-configuration.nix
   ```
3. Create `default.nix` — use an existing host as a template
4. Add entry to `flake.nix` → `nixosConfigurations`
5. Build:
   ```bash
   sudo nixos-rebuild switch --flake .#YOUR-HOSTNAME
   ```

### Template `default.nix`

```nix
{ config, pkgs, lib, ... }:

let
  cfg = import ../../settings/config.nix;
in
{
  imports = [
    ./hardware-configuration.nix
    ../../modules/common.nix
    ../../modules/users.nix
    ../../modules/desktop.nix    # Remove for headless
    ../../modules/packages.nix   # Remove for headless
    ../../modules/services.nix   # Remove for headless
  ];

  networking.hostName = "YOUR-HOSTNAME";

  system.stateVersion = cfg.system.stateVersion;
}
```

### Adding to `flake.nix`

```nix
YOUR-HOSTNAME = mkNixOS {
  system   = "x86_64-linux";
  hostFile = ./hosts/YOUR-HOSTNAME;
  hostName = "YOUR-HOSTNAME";
};
```
